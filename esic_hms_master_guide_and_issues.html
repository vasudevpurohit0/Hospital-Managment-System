Part 2: The Perfect End-to-End ESIC Hospital Workflow Workflow Spec

How a patient moves through the ESIC Hospital System from arrival to discharge:

1
Reception Desk
Verify ESIC IP # (10-digits), fetch dependents, assign UHID & print Queue Token.
2
OPD Queue
Token caller station calls token (e.g. T-0043). Patient enters Doctor Room.
3
Doctor Consultation
3-Panel EMR: Notes, ICD-10 Diagnosis, Rx Prescriptions & Lab orders.
4
Pharmacy Dispensing
FEFO automated batch queue checks stock expiry and dispenses medicine.
5
IPD Ward & Billing
General Ward bed allocation (No VIP beds). Zero-cost insurance clearance.

Defect #1: Pharmacy Dispensing JSON Parsing Crash
P0 - Runtime Crash

Description: Opening Dispensing Queue displays a red error banner: Unexpected token '<', "<!DOCTYPE "... is not valid JSON.

Root Cause: The frontend calls /api/pharmacy/queue. When the endpoint is unreachable or returns a 404/500 HTML page, res.json() throws a SyntaxError.

Required Code Fix:

// In apps/web/src/screens/pharmacy/PharmacyWorkspace.tsx async function fetchQueue() { try { const res = await fetch('/api/pharmacy/queue'); const contentType = res.headers.get('content-type'); if (!res.ok || !contentType?.includes('application/json')) { // Graceful fallback mock data setQueue(MOCK_PENDING_PRESCRIPTIONS); return; } const data = await res.json(); setQueue(data); } catch (err) { setQueue(MOCK_PENDING_PRESCRIPTIONS); } }
