## Reading order

1. `00-overview.md` — orient yourself.
2. `05-prd.md` — understand the why, the users, and what's explicitly out of scope.
3. `06-requirements.md` — see every requirement, numbered, with priority and traceability.
4. `01-architecture.md`, `02-tech-stack.md`, `03-data-model.md` — see how it's built.
5. `07-functional-spec.md` — the detailed how-it-behaves for each module.
6. `04-phases-and-prompts.md` — start building, one small phase at a time.
