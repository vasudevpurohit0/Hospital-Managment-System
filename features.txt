We need a dedicated administrative section for Therapies / Procedures / Billable Services.

FEATURE 2 — ADMIN-CONTROLLED PRICING
Pricing must be fully dynamic.
Authorized Administrator/SuperAdmin users should be able to manage prices without developer intervention.
This should eventually cover:
OPD consultation
IPD bed
IPD room
Laboratory tests
Therapies
Procedures
Diagnostic services
Nursing/service charges where applicable
Packages
Pharmacy charges where applicable
Future billable services
Create a centralized Service & Pricing Master if the existing architecture does not already provide one.
Critical pricing rule
If Admin changes a price:
NEW transactions use the new price.
OLD transactions NEVER change.
Example:
Therapy A
20 Aug → ₹500
29 Aug → Admin changes to ₹700

Old bill → ₹500
New bill → ₹700
Therefore design:
Current price
Effective date
Price history
Changed by
Audit trail
Do not simply overwrite the existing price.
