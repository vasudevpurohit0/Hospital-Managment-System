Stage Actor / Role Input Data System Output & State Transition
1. Beneficiary Check Receptionist 10-Digit ESIC IP Number Fetches Insured Person profile & dependents. Generates UHID and OPD Queue Token.
2. Queue Calling OPD Nurse / Doctor Department & Doctor ID Calls next token (e.g. T-0043). Status changes from WAITING to IN_CONSULTATION.
3. Consultation & Rx Doctor Clinical Notes, Diagnoses, Rx Signs prescription digitally. Emits PRESCRIPTION_ISSUED event to Pharmacy Queue.

5. IPD Admission Admission Clerk / Doctor Admission Note & Clinical Ward Allocates General Ward Bed (e.g. B-101). No VIP/Deluxe rooms permitted.

Issue #2: API JSON Parsing & Endpoint Fallback Failures Critical Runtime Defect

Root Cause: When backend endpoints return 404 HTML fallback responses (or NestJS is restarting/offline), fetch() receives an HTML ... response. Calling res.json() directly causes the application to crash with the red banner error: Unexpected token '<', ".

Screen Audit 1: Pharmacy Dispensing Console
Runtime Error

Observed Behavior: The red banner displays: Unexpected token '<', "<!DOCTYPE "... is not valid JSON upon loading the Dispensing Queue.

Developer Fix Action:

  • Wrap API calls in apiFetch() utility that validates contentType.includes('application/json') before parsing.
  • Provide graceful offline fallback array (e.g. mock pending prescriptions) when API returns non-200 or non-JSON.
